# askap-beam-analysis

Python package and demo notebook for characterising ASKAP holography beam data products.

## Overview

`holopy` is a purpose-built Python package for analysing the FITS data products generated by the ASKAP holography beam-characterisation pipeline. It provides six submodules:

| Module | Purpose |
|---|---|
| `holopy.io` | Load and inspect holography FITS cubes and Taylor-term images |
| `holopy.beam` | Per-beam statistics: FWHM, centroid, sidelobe level, radial profile |
| `holopy.stokes` | Stokes IQUV images, fractional polarisation maps |
| `holopy.frequency` | Per-channel RMS, flagging, bandwidth smearing |
| `holopy.taylor` | Taylor-term analysis, beam prediction at arbitrary frequency, amplitude uniformity |
| `holopy.viz` | Visualisation helpers used by the demo notebook |

## Data products supported

- **Frequency cube** — shape `(beams, Stokes, freq, dec, ra)` e.g. `(36, 4, 288, 101, 101)`
- **Taylor-term image** — shape `(beams, Stokes, taylor, 1, dec, ra)` e.g. `(36, 4, 3, 1, 101, 101)`

## Demo notebook

`holopy_demo.ipynb` walks through a complete 20-section analysis of a closepack-36 SB, including:
- Data loading and header inspection
- Bad-pixel / NaN diagnostics
- Global and cross-beam channel consistency checks
- Single-beam and all-beams grid visualisation
- Stokes panel and fractional polarisation maps
- IQUV frequency spectra
- Channel flagging
- Taylor-term inspection and frequency reconstruction
- Cross-beam FWHM and sidelobe comparison
- Radial profiles and bandwidth smearing
- T₀ amplitude uniformity across all 36 beams

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install numpy matplotlib astropy scipy
python -m ipykernel install --user --name askap-beams --display-name "Python (askap-beams)"
```

Then open `holopy_demo.ipynb` and select the `Python (askap-beams)` kernel.
